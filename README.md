This analysis is for the Mental Illness Dataset.
https://www.kaggle.com/datasets/imtkaggleteam/mental-health

This analysis explores the prevalence of various mental illnesses across different entities (countries) over time, using the `1- mental-illnesses-prevalence.csv` dataset.

The dataset contains **6420 entries** and **8 columns**, covering a time span from **1990 to 2019**. The key columns include:

*   **Entity**: The country or geographic region.
*   **Code**: The country code (contains 270 missing values).
*   **Year**: The year of data collection.
*   **Prevalence of mental disorders**: Columns representing the share of the population affected by:
    *   Schizophrenia disorders
    *   Depressive disorders
    *   Anxiety disorders
    *   Bipolar disorders
    *   Eating disorders

All prevalence data is age-standardized and considers both sexes. The dataset is largely complete, with missing values only observed in the 'Code' column.
